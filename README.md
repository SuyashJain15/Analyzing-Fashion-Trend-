# Fashion Trend Analyzer

A web application that takes the guesswork out of fashion by analyzing outfit photos and telling you how well they match current trends. Built using Python and Flask, this project uses machine learning models to detect clothing items and compare them against real-world fashion trends.

## What it does

- **Outfit Analysis:** Upload a photo and get a breakdown of colors, patterns, and clothing items.
- **Trend Verdict:** See whether your outfit is considered trending or outdated.
- **Outfit Comparisons:** Upload two different outfits to see which one ranks higher on the trend scale.
- **Personalized Recommendations:** Get suggestions on how to improve your look, including layering and color choices.
- **Occasion Detection & Shopping:** It guesses the occasion for your outfit and generates shopping links for related items.
- **Interactive Chatbot:** Ask questions about fashion advice directly within the app.

## Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Machine Learning:** scikit-learn (Logistic Regression, Random Forest classifiers)

## Getting Started

1. Clone this repository.
2. Install the required packages (ensure you have Python installed).
3. Run the application:
   ```bash
   python app.py
   ```
4. Open your browser to `http://127.0.0.1:5000` to start using the tool.
