# Fashion Trend Analyzer 👗👔

Hey everyone! I built this cool little web app that takes your outfit photos and basically tells you if you're dressing well or need some help (lol). It uses Python, Flask, and some machine learning magic to figure out what you're wearing and compares it to current fashion trends. 

I've always found it hard to keep up with what's trending, so I thought, why not let AI do it for me?

## What it actually does

* **Outfit Breakdown:** Just drop a photo in, and it'll pick apart the colors, patterns, and what items you have on.
* **Trend Check:** It'll give you a straight-up verdict: Trending or Outdated. (Don't take it too personally if it roasts your fit!)
* **Outfit Battles:** Stuck between two outfits? Upload both and it'll tell you which one ranks higher. 
* **Style Tips & Shopping:** It guesses where you might be going (like a casual hangout or a formal thing), gives you layering/color tips, and even drops some shopping links.
* **Chatbot:** I also threw in a chatbot so you can just ask for fashion advice right on the page.

## Stuff I used to build it
* **Backend:** Python & Flask
* **Frontend:** Standard HTML/CSS/JS with some Bootstrap to make it look decent
* **ML stuff:** scikit-learn (using Logistic Regression & Random Forests for the heavy lifting)

## How to run it locally

1. Clone the repo to your machine.
2. Make sure you have Python installed and install the required packages.
3. Run the app:
   ```bash
   python app.py
   ```
4. Go to `http://127.0.0.1:5000` in your browser and start uploading fits!
